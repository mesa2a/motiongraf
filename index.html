EPISODE 02

Tips動きを作るコツ

カタログ全体で繰り返し使っている考え方を 6 つにまとめました。

01

ホバーは transition、登場は animation

状態の変化（:hover、.open）は transition、勝手に動くもの（ループ、登場）は @keyframes。デモの「自動再生」の部分は実装では不要です。

.btn:hover::before { translate: 0 0; }
02

行き過ぎてから戻る

出てくる時に少し大きくなってから戻る。第 2 引数が 1 を超える cubic-bezier で作れる。1.3 で上品、1.6 でコミカル。

cubic-bezier(.3, 1.3, .5, 1)
03

ずらす

複数の要素は同時に動かさず、--i を振って animation-delay を少しずつ変える。負の delay なら最初から途中の状態で始められる。

animation-delay: calc(var(--i) * .08s);
04

継ぎ目なくループさせる

2 セット並べて半分だけ動かす（マーキー、雲）、タイル 1 枚分だけ動かす（グリッド、雪）、両端を同じ色にする（グラデ）。ループの瞬間が見えなければ無限に見える。

@keyframes marquee { to { translate: -50% 0; } }
05

隠れている瞬間に差し替える

画面転換や画像の出現は「覆う → 差し替える → 開く」。差し替えは steps(1) の opacity や clip-path の切り替えで一瞬に。

animation: scene-swap 4s steps(1) infinite;
06

動かすのは 4 つだけ

transform・opacity・clip-path・filter はレイアウトを走らせない。高さ auto を動かしたい時は grid-template-rows: 0fr → 1fr。スクロール連動は animation-timeline。

translate: -50% -50%; rotate: 5deg;
EPISODE 03

How to use使い方

コピーして貼るだけ。JavaScript はクラスを付け外しする数行で済みます。

  1. 1

    HTML と CSS をコピーする

    各カードの「コード」を開くと、先頭のコメントに HTML、その下に CSS が出ます。白フラッシュやデモ用ボタンなど共通の土台を使う演出は、いちばん上の「共通パーツ」の CSS も一緒に貼ってください。寸法の cqi は、自分のサイトでは px や rem に読み替えると扱いやすくなります。フォントは Google Fonts の Noto Sans JP と Arvo、かっこいい側は Dela Gothic One と Bebas Neue を使っています。

  2. 2

    .play を付けて再生する（ループ系・登場系）

    アニメーションは .stage.play の下だけで定義されています。表示されたタイミングで付けるなら IntersectionObserver を使います。もう一度再生したいときは、クラスを外して強制リフローしてから付け直します。ホバー系は .play 不要で、:hover のルールだけ残せば動きます。

    const io = new IntersectionObserver(entries => {
  for (const e of entries) e.target.classList.toggle('play', e.isIntersecting);
}, { threshold: 0.25 });
document.querySelectorAll('.stage').forEach(s => io.observe(s));

// もういちど
function replay(stage) {
  stage.classList.remove('play');
  void stage.offsetWidth;        // 強制リフローでアニメーションをリセット
  stage.classList.add('play');
}
  3. 3

    速度調整と、動きが苦手な人への配慮

    すべての animation-duration は calc(時間 / var(--speed)) になっているので、--speed: 2 にすれば倍速になります。OS で「視差効果を減らす」を選んでいる人には自動再生しないようにしましょう。このページは、その設定のときは「もういちど」を押した場合だけ再生します。

    .stage { --speed: 1; }           /* 2 で倍速、.5 で半速 */

@media (prefers-reduced-motion: reduce) {
  .stage.play * { animation-play-state: paused; }   /* 自動再生を止める */
}
